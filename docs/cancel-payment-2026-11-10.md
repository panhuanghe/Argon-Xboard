# 订单详情取消支付

v1.2.36 在待支付订单详情的“继续支付”旁增加“取消支付”。按钮只在后端订单状态为 0 时显示，处理中、已取消、已完成和已折抵订单均不提供取消入口。

复用现有 `/api/v1/user/order/cancel`，通过 POST 提交订单的 trade_no。订单列表的取消按钮和详情入口共享处理函数。按钮请求期间禁用，防止重复提交；只在后台返回 true 时显示取消成功并重新读取页面。请求失败时保留后端错误和重试入口，页面已切换时不处理旧响应。

同一订单的付款设置、实际结算和取消操作互斥。请求期间同时禁用该订单的继续支付和取消按钮，关闭支付窗口也不会解除仍在处理的结算请求锁。

参考 cedar2025/Xboard 提交 `d826a3b32f73bde24acce2a3ab033c6538ce121d` 的 `OrderController::cancel` 和 `OrderService::cancel`：后端检查订单归属和待支付状态，并在事务中取消订单、退回 balance_amount。主题不直接修改余额或订单状态。

验证：4 项取消功能单元测试通过；`tests/order-cancel.browser.cjs` 在 390px/1510px 下覆盖成功、失败、处理中、已取消、已完成和折抵，共 16 个场景通过，包含慢取消/慢付款设置时的操作互斥验证。后台取消后重新读取状态、取消轮询和返回仪表盘读取余额均经过隔离响应验证。没有取消真实订单或执行真实退款。

此修改与 Clash Verge 原生格式对齐一并提交发布 v1.2.36。上传主题更新后即可使用；发布不自动替换线上主题。
