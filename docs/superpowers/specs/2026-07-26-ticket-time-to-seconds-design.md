# 工单列表秒级时间设计

## 目标

将用户端“我的工单”列表中的“创建时间”和“最后回复时间”显示为精确到秒的浏览器本地时间，同时保持其他页面现有日期格式不变。

## 方案

- 在 `assets/theme.js` 中增加工单专用的纯格式化函数 `ticketDateTime(value)`。
- 继续兼容 Xboard 返回的秒级和毫秒级 Unix 时间戳。
- 使用浏览器本地时区，输出固定格式 `YYYY/MM/DD HH:mm:ss`。
- 工单列表首次渲染时，两列都调用 `ticketDateTime()`。
- 列表局部刷新时，“最后回复时间”继续调用同一个函数，避免刷新前后格式不一致。
- 不修改全局 `date()`，从而不影响邀请、订单、订阅到期时间和其他页面。

## 异常处理

- 空时间值沿用现有长期/空值文案行为。
- 无效时间值不抛出页面级异常，返回现有长期/空值文案。

## 验证

- 先增加失败测试，确认本地时间输出包含时、分、秒。
- 测试首次渲染中的创建时间和最后回复时间均使用新函数。
- 测试列表刷新后的最后回复时间仍使用新函数。
- 运行完整 Node 测试、JavaScript 语法检查和 `git diff --check`。

## 非目标

- 不修改 Xboard 后端时间字段或时区。
- 不改变其他页面的日期显示格式。
- 不在本次改动中升级版本、打包或发布。
