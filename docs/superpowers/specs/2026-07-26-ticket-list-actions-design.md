# 工单列表统计与操作设计

## 目标

增强用户端“我的工单”页面的信息密度和操作效率，同时保持 Argon-Xboard 现有视觉风格以及 Xboard 接口兼容性。

## 范围

- 将第三张橙色统计卡从“有新回复”改为“已关闭工单”，数值为列表中 `status != 0` 的工单数量。
- 工单列表保留主题、状态、回复状态和创建时间，并增加“最后回复时间”与“操作”两列。
- “最后回复时间”使用工单的 `updated_at`，字段缺失时回退到 `created_at`。
- 操作列提供“查看”和“关闭工单”。“查看”继续打开现有工单详情弹窗。
- 已关闭工单的“关闭工单”按钮显示为禁用状态，不再发送请求。
- 关闭未关闭工单前显示主题内二次确认对话框；确认后调用现有 `/user/ticket/close` 接口，取消则不产生请求。
- 关闭成功后关闭确认框，显示成功提示，并刷新工单列表、统计数量和行状态。
- 保持右上角全局铃铛的公告提醒行为不变。

## 交互与视觉

- 统计卡沿用现有橙色铃铛图标和渐变，仅替换数值及标题，避免改变页面布局。
- 桌面表格的操作项使用轻量文字按钮和分隔符，视觉参考 vitayr 的“查看｜关闭”，但颜色、字号和交互状态遵循 Argon-Xboard 现有变量。
- 窄屏允许表格横向滚动，按钮保持可点击区域，不压缩关键信息。
- 二次确认使用现有全局对话框与按钮体系；危险操作使用危险色，取消使用次要按钮。

## 数据与错误处理

- 所有统计均基于已经获取的工单列表计算，不增加列表阶段的逐条详情请求。
- 日期继续复用主题的 `date()` 格式化函数。
- 关闭接口失败时保留列表和确认框状态，并显示接口错误提示，允许用户重试或取消。
- 轮询刷新时同步更新工单行、最后回复时间、关闭状态和已关闭数量。

## 验证

- 自动测试覆盖：已关闭数量、最后回复时间回退、开放/关闭工单操作状态及二次确认后才调用关闭接口。
- JavaScript 语法检查通过。
- 人工检查桌面和窄屏布局，确认现有“查看详情、回复工单、公告铃铛”行为无回归。

## 非目标

- 不修改 Xboard 后端或数据库。
- 不改变工单发送者判断、回复状态语义或全局通知逻辑。
- 不增加批量关闭、筛选、分页或删除工单功能。
