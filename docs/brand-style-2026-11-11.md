# 品牌区样式调整

按用户提供的参考图调整左上角品牌区。根据后续反馈，不再重绘图标，直接使用用户提供的 512×512px 原图缩放转换，只将与图片边缘相连的黑色外底转换为透明。保留原图的渐变、白色星形、中心方块和点阵；字标增加青色圆点、间隔较宽的 DASHBOARD 字样和短下划线。品牌名称依旧由后台 brandName/title 配置提供，不固定写成“枫叶云”。

使用 `assets/brand-symbol.png` 保存 108×108px 的高清缩放图，`brand()` 通过已有 ASSETS_BASE 引用，因此根域、子目录安装和本地预览均沿用现有资源路径。默认图标仍显示为 38×38px；用户自定义图片仍为 36×36px，优先使用已有 logoUrl 设置。

浏览器图标由同一原图生成：`favicon.ico` 包含 16/32/48/64px，`assets/favicon-32.png` 为 32×32px。正式模板和预览都引用主题自己的图标，正式模板使用文件修改时间作缓存版本。启动占位图也使用原图，删除两种入口的 boot-line 和其 CSS/keyframes；后续页面的数据加载行为不变。

默认图标上的 CSS 光带每 6 秒扫过一次。动画只作用于默认图标，使用 transform/opacity；开启 prefers-reduced-motion 后关闭扫光并隐藏光带。手机及深色模式保持现有字体大小和配色对比，没有新增主题开关或动画依赖。

验证：`tests/brand.browser.cjs` 检查 320/390/1510px × 浅色/深色共 6 个场景，原图加载、38px 尺寸、名称、扫光及减少动态效果均通过。额外检查自定义 Logo、长品牌名和登录页品牌区、脚本执行前没有启动加载条，以及正式模板/预览的 favicon 引用。转换脚本验证尺寸、透明外角、图案样本像素和 ICO 所含尺寸。59 项既有回归检查及 JavaScript 语法、diff 空白检查通过。
